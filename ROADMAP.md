# nflrest — Implementation Roadmap

> Work in progress. The package skeleton and data layer are in place, and the
> first two analytical metrics are implemented. The remaining engine,
> ingestion, and release work is listed below.

## Phase 0 — Scaffolding (complete)
- [x] Package tree (`R/`, `tests/testthat/`, `man/`, `data-raw/`)
- [x] `DESCRIPTION` with lean Imports (cli, tibble)
- [x] `NAMESPACE` and function docs generated by roxygen2
- [x] Test scaffolding with shared offline fixtures

## Phase 1 — Data layer (complete)
- [x] `data-raw/process_data.R` builds the 2024-2025 schedule sample
- [x] `data-raw/nfl_airports.R` builds the team home-airport lookup
- [x] `data-raw/nfl_stadiums.R` builds the venue lookup
- [x] 15 neutral-site games mapped to the venue actually played in
- [x] Data-integrity tests: every team and venue joins; neutral games are not
      recorded at the home team's own stadium

## Phase 2 — Rest and travel engine (partial)
- [x] `calculate_rest_disparity(schedule)` — rest days per team-season,
      rest disparity, short-week and off-bye flags
- [x] Rest cross-validated exactly against nflverse `home_rest`/`away_rest`
      on all 1,076 non-opener team-games
- [x] `calculate_travel_miles(schedule)` — out-and-back miles, with neutral
      sites charged to both teams
- [x] `summarize_travel_miles(travel)` — season totals and longest trips
- [ ] `flag_time_zone_shifts(schedule, team_tz)` — date-aware body-clock shift
- [ ] `calculate_schedule_advantage(...)` — composite rest + travel + time-zone
- [ ] Historical team aliases (OAK, SD, STL, WSH) for pre-2020 seasons

## Phase 3 — Ingestion and cache (not started)
- [ ] `.nflrest_cache()` — lazy `cachem::cache_mem()` singleton
- [ ] `.fetch_schedules(seasons)` — memoised `nflreadr::load_schedules()`
- [ ] `.fetch_pbp(seasons, weeks)` — optional play-level pull
- [ ] `clear_cache()` export
- [ ] `.onLoad()` option defaults and `.onAttach()` banner

## Phase 4 — Docs and testing (partial)
- [x] Roxygen docs for the implemented functions and datasets
- [x] Offline tests for rest, travel, and data integrity
- [ ] Live integration tests guarded by `skip_if_offline()` + `skip_on_cran()`
- [ ] Vignette (built in CI; pandoc is not available locally)
- [ ] pkgdown site
- [ ] GitHub Actions: R-CMD-check, test coverage

## Phase 5 — Release prep (not started)
- [ ] `NEWS.md` and `usethis::use_release_issue()`
- [ ] Final paper and five-minute demo
